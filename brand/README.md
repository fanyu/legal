# Flowwish logo

A shooting star: a vermilion five-point star, leaning 16° like the italic
wordmark, trails an ink tail painted as one quick dry-brush stroke (飞白) that
runs solid by the star and parts into bristles toward its far end. A gap of
paper separates the tail from the star. It sits next to the wordmark "flowwish"
in EB Garamond Italic with its fl ligature. 流 is flow, and a shooting star is
what you make a wish on. The name is one word: write it **Flowwish** in text and
**flowwish** only in the logo.

Everything in `svg/` and `png/` is generated by `generate.py`; edit the script,
not the files.

## Files

| File | Use |
| --- | --- |
| `flowwish-logo` | Horizontal logo, the default (PNG 2400 px wide) |
| `flowwish-logo-stacked` | Stacked logo for square or centred layouts (PNG 1600 px wide) |
| `flowwish-symbol` | The shooting star alone, where the name already appears nearby (PNG 1024 px) |
| `flowwish-wordmark` | The name alone, its i dotted with a small shooting star (PNG 2000 px wide) |
| `flowwish-avatar` | Square profile picture on the night tile, the default (PNG 1024 and 512 px) |
| `flowwish-avatar-paper`, `flowwish-avatar-vermilion` | The same on paper and on vermilion, for pairings that need them (PNG 1024 and 512 px) |
| `flowwish-favicon` | Rounded app-style tile, as used for the site icon (PNG 512 px) |
| `flowwish-banner-3x1`, `-4x1`, `-16x9` | Profile headers behind the avatar (see [Profile banners](#profile-banners)) |

Each logo, symbol and wordmark comes in four colourways:

| Suffix | Colours | Background |
| --- | --- | --- |
| (none) | Ink with a vermilion star | Light |
| `-reverse` | Night ink with a night vermilion star | Dark |
| `-black` | Ink only | Light, single-colour printing |
| `-white` | White only | Dark or photographic, single-colour printing |

In the horizontal and stacked logos the i keeps its round dot, so the logo
never shows two stars. The starred i belongs to the wordmark on its own.

The SVGs are plain filled paths with no fonts, strokes or filters, so they look
the same in every browser, editor and printer.

## Sizes

The shooting star is drawn in four cuts, each for a range of sizes, and
`generate.py` picks the cut for every file.

| Cut | Size of the shooting star | Drawing | Used for |
| --- | --- | --- | --- |
| Full | 64 px and up | The whole dry brush | Colour logos and avatars, homepage hero, share images, banners |
| Mono | Any, in one colour | The full brush with a wider gap | `-black` and `-white`, vermilion avatar and banner |
| Mid | About 32 to 64 px | A few long streaks and the split end | Site top bars, `flowwish-favicon`, 48 px favicon, touch icon |
| Small | Under 32 px | A bigger star and a short solid tail | `favicon.svg`, 16 and 32 px favicon |

## Profile banners

The shooting star crosses a sky of small distant stars. It sits right of centre,
away from the avatar, which most sites place at the bottom left, and the
distant stars keep clear of both.

| Size | Pixels | For |
| --- | --- | --- |
| `3x1` | 1500 × 500 | X, Bluesky, Mastodon |
| `4x1` | 1584 × 396 | LinkedIn profile |
| `16x9` | 2560 × 1440 | YouTube; the shooting star stays inside the central 1546 × 423 that every device shows |

| Suffix | Banner | Avatar to pair with |
| --- | --- | --- |
| (none) | Paper | `flowwish-avatar`, the default pairing |
| `-dark` | Tile | `flowwish-avatar-paper` or `flowwish-avatar-vermilion`; the default avatar has the banner's colour |
| `-vermilion` | Vermilion | `flowwish-avatar` |

For another site's size, add a row to `BANNER_SIZES` in `generate.py`.

## Use

- Keep clear space around the logo at least the height of the star.
- Use the horizontal logo at 24 px tall or larger on screen. Below that, use the
  symbol or the favicon, which have their own cuts for small sizes.
- One-colour versions use the mono cut, whose wider gap keeps the star apart
  from the tail once colour no longer does; don't recolour the colour version
  to one colour.
- Don't set the name in live type next to the shooting star, stretch or rotate
  the logo, or move the shooting star relative to the wordmark.

## Regenerate

```sh
python3 brand/generate.py
```

It needs `rsvg-convert` (librsvg) and Google Chrome on macOS, where the share
images get their system font. Besides `svg/` and `png/`, it:

- rewrites the inline logo in every page of the site: `<svg class="wm">` gets
  the horizontal logo, `<svg class="wm wm-stack">` the stacked one and
  `<svg class="wm wm-word">` the wordmark with the starred i;
- writes the hero's entrance keyframes between the marker comments in
  `assets/site.css`: the star flies in along its path while the tail unfurls
  behind it (reduced motion turns this off);
- replaces `assets/favicon.svg`, `favicon.ico`, `apple-touch-icon.png`,
  `assets/og.png` and `assets/og-zh.png`.

On the site, `currentColor` and the `--accent` variable colour the inline logo,
so it follows dark mode.

## Redraw the shooting star

`source/meteor.json` holds the outlines of every cut, the star over the i (in
the wordmark's font units) and the star's flight path for the animation, so
regenerating needs no geometry library. To change the drawing, edit
`tools/meteor.py`, then run:

```sh
cd brand
python3 tools/meteor.py > source/meteor.json
```

It needs shapely (`pip install shapely`). The streaks of the dry brush come from
fixed seeds, so every run draws the same mark.

## Redraw the wordmark

`source/wordmark.json` holds the outlined wordmark, so regenerating needs no
font. To change it, get EB Garamond Italic (SIL Open Font License) from
https://github.com/octaviopardo/EBGaramond12 and run:

```sh
cd brand
python3 tools/wordmark.py EBGaramond-Italic.ttf | swift tools/outline.swift > source/wordmark.json
```

`wordmark.py` shapes the text with HarfBuzz (`hb-shape`) and fontTools;
`outline.swift` thickens it with a round stroke and merges it into plain
outlines. Don't commit the font file. If the outlines change, check that `DOT`
in `generate.py` still points at the i's dot, which the starred wordmark
replaces, and that the star in `tools/meteor.py` (`WORD_C`) still sits over it.
