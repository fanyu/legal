# Flowwish logo

A folded paper boat whose top edge reads as a W, with a vermilion sail, next to
the wordmark "flowwish" in EB Garamond Italic with its fl ligature. The name is
one word: write it **Flowwish** in text and **flowwish** only in the logo.

Everything in `svg/` and `png/` is generated by `generate.py`; edit the script,
not the files.

## Files

| File | Use |
| --- | --- |
| `flowwish-logo` | Horizontal logo, the default (PNG 2400 px wide) |
| `flowwish-logo-stacked` | Stacked logo for square or centred layouts (PNG 1600 px wide) |
| `flowwish-symbol` | The boat alone, where the name already appears nearby (PNG 1024 px) |
| `flowwish-wordmark` | The name alone, where the boat would be too small (PNG 2000 px wide) |
| `flowwish-avatar`, `flowwish-avatar-dark` | Square profile pictures, full bleed (PNG 1024 and 512 px) |
| `flowwish-favicon` | Rounded app-style tile, as used for the site icon (PNG 512 px) |
| `flowwish-banner-3x1`, `-4x1`, `-16x9` | Profile headers behind the avatar (see [Profile banners](#profile-banners)) |

Each logo, symbol and wordmark comes in four colourways (the wordmark has no
`-black`, because its colour version is already ink):

| Suffix | Colours | Background |
| --- | --- | --- |
| (none) | Ink with a vermilion sail | Light |
| `-reverse` | Night ink with a night vermilion sail | Dark |
| `-black` | Ink only | Light, single-colour printing |
| `-white` | White only | Dark or photographic, single-colour printing |

The SVGs are plain filled paths with no fonts, strokes or filters, so they look
the same in every browser, editor and printer. The one exception is the banners,
whose fine lines are strokes.

## Profile banners

A current of fine lines parts around the boat and closes behind it, so the boat
sails to the right. The boat sits right of centre, away from the avatar, which
most sites place at the bottom left.

| Size | Pixels | For |
| --- | --- | --- |
| `3x1` | 1500 × 500 | X, Bluesky, Mastodon |
| `4x1` | 1584 × 396 | LinkedIn profile |
| `16x9` | 2560 × 1440 | YouTube; the boat stays inside the central 1546 × 423 that every device shows |

| Suffix | Banner | Avatar to pair with |
| --- | --- | --- |
| (none) | Paper | `flowwish-avatar`, the default pairing |
| `-dark` | Tile | `flowwish-avatar` |
| `-vermilion` | Vermilion | `flowwish-avatar-dark`; the red avatar would merge into it |

For another site's size, add a row to `BANNER_SIZES` in `generate.py`.

## Colours

| Name | Hex | Role |
| --- | --- | --- |
| Ink | `#1b1c1f` | Boat hull and wordmark on light backgrounds |
| Vermilion | `#d63f2a` | Sail; avatar and favicon background |
| Paper | `#f6f3ec` | Boat on vermilion |
| Night ink | `#f2efe8` | Boat hull and wordmark on dark backgrounds |
| Night vermilion | `#e8452c` | Sail on dark backgrounds |
| Tile | `#17191e` | Dark avatar background |

## Use

- Keep clear space around the logo at least the height of the sail.
- Use the horizontal logo at 24 px tall or larger on screen. Below that, use the
  symbol; the favicon has its own cuts for 16, 32 and 48 px with a wider fold.
- One-colour versions separate the sail from the hull by the fold alone, so
  their gap is wider; don't recolour the colour version to one colour.
- Don't set the name in live type next to the boat, stretch the logo, or move
  the boat relative to the wordmark.

## Regenerate

```sh
python3 brand/generate.py
```

It needs `rsvg-convert` (librsvg) and Google Chrome on macOS. Besides `svg/` and
`png/`, it rewrites the inline logo in every page of the site (`<svg class="wm">`
gets the horizontal logo, `<svg class="wm wm-stack">` the stacked one) and
replaces `assets/favicon.svg`, `favicon.ico`, `apple-touch-icon.png`,
`assets/og.png` and `assets/og-zh.png`. On the site, `currentColor` and the
`--accent` variable colour the inline logo, so it follows dark mode.

## Redraw the wordmark

`source/wordmark.json` holds the outlined wordmark, so regenerating needs no
font. To change it, get EB Garamond Italic (SIL Open Font License) from
https://github.com/octaviopardo/EBGaramond12 and run:

```sh
cd brand
python3 tools/wordmark.py EBGaramond-Italic.ttf | swift tools/outline.swift > source/wordmark.json
```

`wordmark.py` shapes the text with HarfBuzz (`hb-shape`) and fontTools;
`outline.swift` thickens it with a round stroke and merges it into plain
outlines. Don't commit the font file.
