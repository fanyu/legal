PasteFlow 隐私政策 / Privacy Policy

生效日期 / Effective date：2026-10-04
联系邮箱 / Contact： support@flowwish.app

本政策说明 PasteFlow（以下简称“本应用”）如何处理您使用 macOS 版 PasteFlow 时产生的数据。请在使用本应用前阅读本政策。本应用将剪贴板数据保存在您的 Mac 本地，不提供 iCloud 同步，也不运营用于收集剪贴板内容的开发者服务器。只有您主动导出备份或发送反馈时，相关数据才会离开本应用的本地存储范围。

This policy explains how PasteFlow (the “App”) handles data when you use the macOS version of PasteFlow. Please read it before using the App. The App stores clipboard data locally on your Mac, does not provide iCloud sync, and does not operate a developer server for collecting clipboard contents. Relevant data leaves the App's local storage boundary only when you explicitly export a backup or send feedback.

中文版

1. 本应用处理哪些数据

PasteFlow 是剪贴板历史工具。根据您启用的功能，本应用可能在您的 Mac 上处理：

  • 剪贴板中的文字、图片、文件引用、链接以及相关的创建时间、内容类型、收藏/置顶和使用状态；
  • 您的收藏/置顶状态和设置；
  • 您主动导出的备份文件，及您主动选择导入的备份文件；
  • Apple 处理付费下载的付款信息；本应用不会接收您的完整支付卡信息。

本应用不会为了分析、广告或建立用户画像而收集剪贴板内容。剪贴板内容可能包含个人信息或敏感信息，因此请只复制和保存您有权处理的内容。

2. 数据在哪里保存

  • 本地存储： 剪贴板历史、收藏/置顶和设置默认保存在您 Mac 的本地应用数据中。开发者无法通过 PasteFlow 的服务器读取这些数据，因为本应用没有用于此目的的开发者数据后台。
  • 敏感内容控制： 您可以使用应用排除规则、敏感内容自动过期和备份排除等本地控制。若您开启“本地加密”选项，敏感文本内容会在本机使用系统钥匙串保存的密钥进行加密存储；本应用不因此声称所有普通剪贴板历史都已加密。
  • 不提供云同步： 当前版本不提供 iCloud 或其他多设备同步。剪贴板历史和设置不会由 PasteFlow 上传到云端。
  • 备份与导入： 备份只有在您主动选择导出位置并确认导出时创建。JSON 备份文件本身不加密。使用本地加密引用的敏感项目始终排除，因为其设备专用密钥和负载不可移植；其他敏感项目遵循您的备份排除设置。如果您选择包含明文敏感项目，本应用会在写入前警告。备份文件由您负责保管。

更新前保存的片段和预设可能继续留在本机应用数据中，但新版本不再提供对应功能。

3. 您主动发出的反馈

本应用提供两种不同的支持途径，请根据公开程度谨慎选择：

  • GitHub Issue 反馈： 选择公开反馈后，本应用会打开 fanyu/PasteFlow-Feedback 的新 Issue 页面。Issue 会包含您输入的标题和内容，以及用于排查问题的应用版本、构建号、macOS 版本、应用语言和时间戳。Issue 对 GitHub 及互联网用户公开；请不要提交剪贴板原文、密码、令牌、个人身份信息或其他机密内容。GitHub 会按照其自身的隐私政策处理公开 Issue 和您的 GitHub 账号信息。
  • 邮件支持： 选择邮件支持会使用您系统中配置的邮件客户端，收件人是 support@flowwish.app。只有您在邮件中主动填写的内容会随邮件发送；邮件及其附件可能由您的邮件服务商处理和保存。

4. 第三方服务、权限与技术数据

PasteFlow 不包含第三方广告、分析、追踪或遥测 SDK，也不在应用后台建立开发者账号系统。Apple 可能根据其自身条款处理 App Store、macOS 系统服务以及您主动使用的其他 Apple 服务所需的技术信息。

本应用可能请求或使用以下 macOS 能力来完成您主动启用的功能：

  • 剪贴板访问，用于监测和保存剪贴板历史；
  • 默认情况下，选择历史记录只会复制内容，请在目标应用中按 ⌘V 粘贴。从 Build 16 测试版本起，用户可在设置中选择开启“选中后直接粘贴”，并主动授予 macOS 管理的事件发送权限。此功能仅在用户按回车或双击选中记录后，向先前使用的应用发送 ⌘V；不读取其他应用的界面，不监听键盘输入。未授权、目标应用不可用或操作中断时，仍可手动粘贴。
  • 文件选择器，用于您主动导出或导入备份；
  • 网络浏览器或邮件客户端，用于打开 GitHub 反馈、隐私政策、使用条款和邮件支持链接。

这些权限不会改变本政策所述的数据处理范围。本应用不会因为您授予权限就将完整剪贴板历史上传给开发者。

5. 保存期限与删除

本地数据会保留到您在应用中删除、清空、导出后自行删除，或您启用的敏感内容自动过期规则将其删除为止。您可以在 PasteFlow 中清理历史，也可以通过 macOS 的应用数据管理方式删除本地数据。开发者不会保留一份独立的剪贴板副本。

已提交到 GitHub 的公开 Issue 和已发送的邮件不受 PasteFlow 本地删除操作控制；如需删除公开 Issue 或邮件，请分别向 GitHub 或您的邮件服务商提出请求。

6. 儿童隐私

PasteFlow 是面向一般 macOS 用户的生产力工具，并非面向儿童设计。本应用不会主动向儿童收集个人信息。

7. 政策更新与联系我们

我们可能因功能、法律或平台要求更新本政策。更新后的版本会在本页面发布，并标注新的生效日期。若您对本政策或数据处理方式有疑问，请联系：

support@flowwish.app

English Version

1. Data the App Handles

PasteFlow is a clipboard history utility. Depending on the features you enable, the App may process the following on your Mac:

  • Clipboard text, images, file references, links, and related metadata such as creation time, content type, favorite/pin state, and usage state;
  • Your favorites/pins and settings;
  • Backup files that you explicitly export, and backup files that you explicitly choose to import;
  • Payment information for the paid download is handled by Apple; the App does not receive your full payment-card details.

The App does not collect clipboard contents for analytics, advertising, or profiling. Clipboard contents may include personal or sensitive information, so only copy and store content that you are authorized to handle.

2. Where Data Is Stored

  • On your Mac: Clipboard history, favorites/pins, and settings are stored in the App’s local application data by default. The developer cannot read this data through a PasteFlow server because the App does not operate a developer backend for this purpose.
  • Sensitive-content controls: You can use local exclusion rules, sensitive-content expiration, and backup-exclusion controls. If you enable local encryption, sensitive text content is encrypted on the Mac with a key stored in the system Keychain. This does not mean that all ordinary clipboard history is encrypted.
  • No cloud sync: The current version does not provide iCloud or other multi-device synchronization. PasteFlow does not upload clipboard history or settings to the cloud.
  • Backups and imports: A backup is created only after you choose a destination and confirm an export. JSON backup files are not encrypted. Sensitive items backed by local encrypted references are always excluded because their device-only keys and payloads are not portable; other sensitive items follow your backup-exclusion setting. If you choose to include plaintext sensitive items, the App warns you before writing them. You are responsible for protecting backup files.

Snippets and presets saved before this update may remain in local app data, although the current version no longer exposes those features.

3. Feedback You Choose to Send

The App offers two support paths with different levels of public exposure:

  • GitHub Issue feedback: Public feedback opens a new issue in fanyu/PasteFlow-Feedback. The issue contains the title and details you enter, plus troubleshooting metadata: app version, build number, macOS version, app language, and timestamp. Issues are public to GitHub and the internet. Do not submit raw clipboard contents, passwords, tokens, personal identifiers, or other confidential information. GitHub handles public issues and GitHub account information under its own privacy policy.
  • Email support: Email support opens the mail client configured on your Mac with support@flowwish.app as the recipient. Only the content and attachments you choose to include are sent; your mail provider may process and retain the message and attachments.

4. Third-Party Services, Permissions, and Technical Data

PasteFlow contains no third-party advertising, analytics, tracking, or telemetry SDKs and does not require a developer-owned account. Apple may process technical information required for the App Store, macOS system services, and other Apple services that you choose to use under Apple’s own terms.

The App may request or use these macOS capabilities for features you actively enable:

  • Clipboard access to monitor and save clipboard history;
  • By default, selecting a history item copies it to the system clipboard; press Command-V in the destination app to paste. Starting with the Build 16 beta, users may enable optional direct paste in Settings and explicitly grant macOS-managed event-posting permission. After the user confirms a history item with Return or a double-click, this feature sends Command-V to the previously used application. It does not read other applications' interfaces or monitor keyboard input. Without permission, or if the target is unavailable or delivery is interrupted, the copied content remains available for manual paste.
  • File pickers for an export or import that you initiate;
  • A web browser or mail client to open GitHub feedback, this policy, the Terms of Use, or email support.

These permissions do not expand the data processing described in this policy. Granting permission does not cause the App to upload your complete clipboard history to the developer.

5. Retention and Deletion

Local data remains until you delete or clear it in the App, delete your exported copy, or an enabled sensitive-content expiration rule removes it. You can clear history in PasteFlow or remove local app data using macOS data-management controls. The developer does not retain a separate copy of your clipboard history.

Public GitHub issues and sent email are not controlled by PasteFlow’s local deletion controls. To request removal of a public issue or an email, contact GitHub or your mail provider respectively.

6. Children’s Privacy

PasteFlow is a general productivity utility for macOS and is not directed to children. The App does not knowingly solicit personal information from children.
